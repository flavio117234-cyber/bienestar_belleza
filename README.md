# Servicios Bienestar y Belleza (Beauty and Wellness)

Sistema web para buscar, comparar y reservar servicios de atención personal y belleza en Xalapa, Veracruz.

## Características
- Registro de clientes y profesionales con foto de perfil.
- Gestión de negocios, servicios e imágenes.
- Sistema de reservas y calificaciones.

## Tecnologías
- PHP
- MySQL / MariaDB (XAMPP)
- HTML5, CSS3, JavaScript

## Configuración local
1. Clona el repositorio en `htdocs/bienestar_belleza`.
2. Importa `database/esquema.sql` en phpMyAdmin (`bd_bienestar_belleza`).
3. Inicia Apache y MySQL en XAMPP.
4. Abre `http://localhost/bienestar_belleza/`.
